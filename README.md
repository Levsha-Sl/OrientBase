# OrientBase

**OrientBase** — инструмент на базе Microsoft Excel для учёта спортсменов в спортивном ориентировании. Он помогает организаторам соревнований, тренерам и представителям клубов хранить сведения о спортсменах, отслеживать сроки действия разрядов и страховок и сверять заявки с накопленной базой.

Проект реализован в виде книги Excel с макросами VBA (`.xlsm`). Основная работа выполняется в привычных таблицах: данные можно редактировать, загружать из CSV и сохранять для дальнейшего использования.

## Зачем нужен OrientBase

При подготовке соревнований приходится повторно проверять сведения об участниках: ФИО, даты рождения, разряды и страховки. Когда эти данные находятся в разных списках, сверка занимает время, а изменения легко пропустить.

OrientBase собирает сведения в одной базе и позволяет использовать их при обработке следующих заявок. Автоматический расчёт сроков и цветовая подсветка помогают замечать записи, требующие внимания. Это сокращает объём повторной ручной работы и помогает поддерживать актуальные данные о спортсменах.

## Возможности

- **База спортсменов:** ФИО, дата рождения, разряд, сведения о страховке и дата изменения записи.
- **Контроль сроков:** расчёт дат окончания действия разрядов и страховок с цветовой подсветкой.
- **Справочник разрядов:** настройка сроков их действия.
- **Заявки из Orgeo:** загрузка CSV, выбор клубов и работа со списками их участников.
- **Сверка с базой:** сопоставление спортсменов, добавление новых записей и обновление существующих.
- **Обмен данными:** импорт и экспорт базы в формате CSV.

## Скачать и начать работу

Готовые версии доступны на странице [скачивания OrientBase — Releases](https://github.com/Levsha-Sl/OrientBase/releases).

Для работы используется настольный Microsoft Excel для Windows с поддержкой макросов VBA. Основной файл проекта — `orient_sportsman_database.xlsm`.

Перед началом работы подтвердите стандартные разрешения Excel для этого файла: если появятся соответствующие уведомления, нажмите **«Разрешить редактирование»** и **«Включить содержимое»**, чтобы разрешить выполнение макросов. Без включённых макросов кнопки и автоматические функции OrientBase работать не будут.

Подробная инструкция по настройке и использованию находится в [Wiki проекта](https://github.com/Levsha-Sl/OrientBase/wiki).
